# Bombora Read More Toggle

Modul **Bombora Manageru**. Tag `[read]…[/read]` skryje text za tlačítko „Pokračovat“ – v obsahu, krátkém popisu produktu i v popisu kategorií.

## Vydání nové verze
1. Zvyš `Version:` a `BOMBORA_RMT_VERSION` v `bombora-read-more-toggle.php`.
2. Přidej sekci `## [X.Y.Z]` do `CHANGELOG.md`.
3. Push do `main` → Action vytvoří Release `vX.Y.Z` s `bombora-read-more-toggle.zip` + `.sha256`.
